Manual Claude Desktop config (Windows). Credentials live in .env inside the project folder; do NOT put them here.

{
  "mcpServers": {
    "unanet": {
      "command": "cmd.exe",
      "args": ["/c", "cd /d \"C:\\path\\to\\unanet-mcp-server\" && node dist\\index.js"]
    }
  }
}

macOS equivalent: see README.md ("bash -lc" + "cd <repo> && node dist/index.js").
